# Simple Python QR Code Generator

## 📌 About The Project
This project is a simple yet effective Python script to generate a QR code from a given URL or text. It is designed to demonstrate how to use Python's external libraries for automation and content creation. In this example, the script generates a QR code pointing to my personal GitHub profile.

## ✨ Features
* **URL/Text to QR:** Encodes any string of text or a full URL.
* **Automatic Save:** Generates and saves the QR code as a high-quality `.png` image file.
* **Open-Source & Modifiable:** Easily change the destination URL or output filename.

## ⚙️ Prerequisites & Installation
